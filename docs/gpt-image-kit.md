# GPT 이미지 제작 자료 다운로드 — 가이드 v2

로컬 발굴 화면에서 상품을 선택하고 오른쪽 **GPT 이미지 제작 · 자료 다운로드**를 누른다. 현재 저장본을 인증된 조회 API로 다시 확인하며, 선택한 revision이 달라졌으면 새로고침 후 재시도한다. 편집 중인 미저장 내용은 포함되지 않는다.

`ChatGPT 제작 요청문 복사`는 같은 저장본에서 명시적인 **상품 상세페이지 제작 요청**을 준비한다. ChatGPT 새 대화에 요청문을 붙여넣고 ZIP을 함께 첨부한다. 앱 개발 요청이 아니며, ZIP 파일만 첨부하면 작업이 자동 실행된다는 뜻이 아니다. 자동 복사가 안 되면 `제작 요청문 보기·직접 복사`를 펼쳐 텍스트를 복사한다.

새 파일명은 `gpt-image-kit-상품ID-r리비전-guide-v2.zip`이다. 이전 ZIP 대신 새 파일을 사용한다. 기본 다운로드 위치는 브라우저의 다운로드 폴더이며 사용자가 변경한 설정이 우선한다.

ZIP 내용:

- `00_ChatGPT_제작요청.txt`: 대화에 직접 붙여넣을 전체 제작 요청문
- `프롬프트.txt`: 위 요청문과 동일한 내용(기존 사용 흐름 호환)
- `제작가이드.md`: 구매 질문별 전체 제작·디자인·납품 기준
- `패널구성안.json`: 13개 정보 모듈의 구매 질문·필요 근거·시각 구성·미확인 상태
- `사진옵션매칭표.json`: 원본/업로드 사진 경로·해시·옵션 ID. 실제 육안 대조 전 SKU 연결은 비워 둠
- `검수표.md`: 문구 근거·상품 변형·한글·권리·판매 정보·파일 한도 검수
- `상품정보.json`: 허용된 상품 필드만 추린 저장본; 원본 응답·인증키·계정 데이터·비용 시나리오 제외
- `originals/`: 내려받은 실제 사진 원본 바이트
- `upload/`: 전체 범위를 보존한 JPG, 긴 사진은 120px 이내 겹침 분할, 가로 최대 1600px로 축소
- `manifest.json`: 원본 URL·SHA-256·분할 좌표·크기·누락 사유
- `사용방법.txt`: 압축 해제 → 프롬프트 붙여넣기 → JPG 직접 첨부 안내

ZIP 하나만 ChatGPT에 올렸을 때 이미지가 인식된다고 보장하지 않는다. 압축을 풀고 사진을 직접 첨부한다. 사진 없는 ZIP은 사진 제작 준비 완료가 아니다. 사진과 SKU가 일치하는지, 사용권·재질·치수·구성·문구가 확인됐는지 사용자가 검수해야 한다.

## 전체 상세페이지 제작 기준

기본 목표는 **8~12개 실제 이미지 패널 / 10~14개 정보 섹션**이다. 대표·사용 불편·특징 요약·특징 상세 A/B·사용 장면·구조·옵션·구성품·크기·관리·FAQ·상품/배송/반품 정보를 상품별로 합치거나 나눈다. 근거가 부족하면 해당 항목을 내부 보류 목록에 남기며, 허위 정보나 같은 설명의 반복으로 분량을 채우지 않는다.

실제 패널 파일, `detailpage-copy.txt`, 사진/SKU/출처를 연결한 `storyboard.json`, 내부 `review.md`를 요청한다. 대표 한 장과 나머지 계획만 제출한 상태는 전체 제작 완료가 아니다. 도구·한도 제한으로 중단되면 미제작 번호와 이어하기 요청문을 남긴다. 폭 860px는 작업 목표이며 실제 생성 크기는 따로 측정한다. 반환 이미지는 기존 앱 한도인 파일당 4MiB/8MP, 상품당 20개/24MiB 이내로 준비한다.

레퍼런스는 IKEA DRONJONS와 Yamazaki의 정보 구성만 참고했다(2026-10-16 조사). 다른 상품의 사진·카피·성능·배송 정책을 복제하거나 이 상품의 근거로 삼지 않는다. 상품명·운영자 초안·사진 비례는 검증된 치수/소재/성능이 아니다. 미확인 사용권·실제 SKU·판매 적합성과 수익성 보류 상태는 바꾸지 않는다.

## 사용자 재시험

1. 메모함 `675246155709`를 선택하고 새 ZIP을 다운로드한다.
2. 제작 요청문을 복사해 ChatGPT 새 대화에 붙이고 ZIP을 첨부한다. 사진을 읽지 못하면 ZIP의 `upload/` JPG를 직접 첨부한다.
3. 전체 패널·카피·storyboard·검수표를 받는다. 실제 파일 수/내용/픽셀 크기와 미제작 항목을 확인한다.
4. 완성 이미지는 Seller OS의 기존 업로드·미리보기 흐름에서 검토한다. 메모함은 흐름 시험용이며 판매 통과 상품이 아니다.

가이드/ZIP 기술 검증과 실제 ChatGPT 제작 품질 검증은 별개다. 이번 구현에서 실제 GPT 이미지를 새로 생성하거나 판매 승인하지 않았다.

사진은 저장된 `https://cbuNN.alicdn.com/` 공개 이미지 주소에서 익명 CORS 요청으로만 받는다. 쿠키·API 키·Referer를 보내지 않으며 리다이렉트, 사용자 인증 정보, 쿼리 문자열, 임의 호스트를 허용하지 않는다. JPG/PNG/WebP의 MIME과 시그니처를 확인한다. 원본당 8MiB, 총 사진 40MiB, 12개 원본, 각 요청 15초 한도. 디코딩 후 최대 16000px/40MP 제한. 차단·한도 초과·변환 실패는 manifest에 남기며, 디코딩 실패 시 받은 원본은 보존할 수 있다.

사진의 의미를 판단하는 크롭, 제품 누끼/배경 제거, 워터마크 제거는 하지 않는다. 실제 상품을 바꾸거나 근거 없는 물성·성능을 생성하지 않는다. 이미지 사용권이 확인되지 않았다면 내부 검토 초안이며 상업 게시 권한을 의미하지 않는다.

GPT 로그인·API 호출·자동 이미지 생성·외부 전송·상품 등록·배송 신청·결제는 이 버튼의 기능이 아니다. 사용자가 ChatGPT에서 직접 제작하며 계정 한도·이용 조건은 별도다. 코드 배포는 별도 승인 사항이며 이번 변경은 로컬 검증이다.

ZIP은 고정 버전 `fflate@0.8.3`의 STORE 방식으로 생성해 이미 압축된 사진을 다시 압축하지 않는다. 공식 사용 안내: https://github.com/101arrowz/fflate .

검증: `node --test test/gptImageKit.test.js test/detailPageGuide.test.js`, `npm test`, `npm run build`. 실제 브라우저 다운로드는 메모함(675246155709/r4, 원본7장·JPG7장)과 사진 없는 P2013(816692570613/r9)으로 확인했다. 다운로드된 사진·ZIP·캡처는 Git에 넣지 않는다.
