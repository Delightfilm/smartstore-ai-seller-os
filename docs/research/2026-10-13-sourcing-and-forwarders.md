## 배송대행 비교

아래는 공개 표의 관찰값이다. 동일한 최종 견적이 아니다. 특히 퀵스타 운임 VAT 포함 여부는 확인하지 못했으며, 계정별 할인과 부피/검수/포장/반품비가 달라 현재 최저가 업체를 확정할 수 없다.

| 업체 | 자동화 확인 | 기본등급 1kg / 2kg 표시값 | 남은 확인 |
|---|---|---|---|
| 퀵스타 | 윈들리·아바닛 공식 가이드에 API 연동 명시 | 해운(자가) 일반셀러 6,200 / 7,800원 | 자체 Seller OS에 직접 연결 가능한 문서·발급 권한·운임 VAT |
| 토스토스 | 공식 Open API 제공, 회원 API 키 화면 존재 | 실제 선택 노선/회원등급을 고정한 견적 재확인 필요 | 키 발급 후 개발 문서·신청/조회/송장 기능 범위 |
| 루트스마일 | 공개 REST 문서: 신청 등록/수정/조회, 비용/상태/국내 송장 조회 | 해운 기본등급 5,600 / 7,300원, VAT 별도 | 키 발급 조건·포장 규격·계약/반품 비용 |

루트스마일 표를 VAT 포함으로 계산하면 1kg 6,160원, 2kg 8,030원이다. 퀵스타에 VAT가 이미 포함돼 있다면 표면상 600원 차이가 실질적으로는 1kg 40원 차이로 줄고, 2kg은 역전될 수 있다. **이 조건은 가정이며 퀵스타 VAT 정책 확인 전에는 우열을 정하지 않는다.**

루트스마일은 공개 API 기능이 구체적이어서 자체 시스템 연결을 검토하기 쉽다는 판단이다. 퀵스타는 제휴 서비스 연동 사례가 있지만 그 사실만으로 임의 자체 프로그램에 같은 API 권한을 준다고 볼 수 없다. 가입/키 발급/유료 신청/주문은 하지 않았다.
