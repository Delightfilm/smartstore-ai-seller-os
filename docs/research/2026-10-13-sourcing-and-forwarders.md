- 사용자 발급 안내의 접근 제한 가이드에서 Open API v1.0의 개요·인증·신청서·조회 명세를 직접 열람했다. 비밀번호, 키 값, 사용자 사업자/사서함 정보 및 인증 HTML은 이 저장소에 보관하지 않는다. 원문은 사용자에게 열린 가이드 탭에서 확인 가능하다.

연동 전 확인이 필요한 사항:

1. 기존 회원 마이페이지의 발급 API 키가 문서상 `tokenKey`와 같은지, 다르면 교환/조회 방법은 무엇인지 명시가 부족하다. 문서의 회원가입 흐름을 기존 계정에 임의 실행하지 않는다. `apiName` 지정 방식도 확인한다.
2. `ExtraSvc` 표와 `extraSvc` 요청 예시의 대소문자가 다르므로 실제 필드명을 확인한다. 조회 GR 번호와 수정/폐기 SH 번호는 분리 저장해야 한다.
3. 예시에는 예치금 자동결제·빠른배송·보험·통관정보 불일치 강제출고가 활성화되어 있다. 구현 때 예시를 그대로 복사하지 않고 기본 비활성 및 별도 승인 정책을 둔다.
4. 확인한 메뉴에서 사전 운임 견적 전용 API, webhook, 호출 한도, 멱등키, sandbox 명세를 찾지 못했다. 실제 측정 후 비용 조회와 사전 견적을 구분한다. 기능이 없다고 단정하지 않는다.
5. 실제 키는 마이페이지에서 조회하지 않았으며 API 요청, 회원 생성, 배송 신청, 결제, 고객정보 전송은 하지 않았다. 문서에 표시된 예시 키도 저장하거나 사용하지 않았다.
